The portfolio uses DM Sans and JetBrains Mono. The blog and studio use Playfair Display, Hanken Grotesk, and JetBrains Mono. All fonts are locally hosted with their OFL licenses:

- https://github.com/google/fonts/tree/main/ofl/dmsans
- https://github.com/google/fonts/tree/main/ofl/playfairdisplay
- https://github.com/google/fonts/tree/main/ofl/hankengrotesk
- https://github.com/google/fonts/tree/main/ofl/jetbrainsmono

Font data is preserved in WOFF2 format. Blog font variables and theme colors are scoped to blog/studio surfaces, preserving the homepage styling.
